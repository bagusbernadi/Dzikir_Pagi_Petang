# Dzikir Pagi & Petang

Website bacaan Dzikir Pagi (21 bacaan) dan Dzikir Petang (20 bacaan), dengan counter per bacaan. Sumber teks: Hisnul Muslim. Satu file HTML tanpa build.

**Live:** https://bagusbernadi.github.io/Dzikir_Pagi_Petang/

## Fitur
- Daftar Pagi/Petang berbentuk accordion, reset hitungan per kategori, kartu "Lanjut dari terakhir", dan garis progress.
- Counter per bacaan: jeda ketukan 0,25 / 0,5 / 1 detik, tombol −1 dan Ulang, getar, auto-lanjut.
- Geser kiri/kanan untuk pindah bacaan (aktif di seluruh layar).
- Latin dan Keutamaan/keterangan sebagai dropdown, ikon Salin.
- Tajwid berwarna otomatis (11 hukum). Ketuk huruf berwarna untuk melihat nama dan cara bacanya, tombol "i" untuk daftar lengkap dengan saklar per hukum.
- Pengaturan (gear): ukuran huruf Arab, jeda ketukan, tema otomatis/terang/gelap.
- Font Arab Naskh (`fonts/naskh.woff2`). Hitungan tersimpan di browser dan reset tiap hari.

## Menjalankan
Buka `index.html` di browser, atau aktifkan GitHub Pages (Settings, Pages, branch `main`, folder root).

Tambah atau ubah bacaan di objek `KAT` di dalam `index.html`.
